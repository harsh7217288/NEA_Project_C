# reports/

Final deliverables for submission/presentation (Week 6) — not working files.

**Suggested contents:**

- `final_report.pdf` (or `.docx`) — the written project report: problem, data,
  methodology, results, limitations, honest scope statement
- `presentation.pptx` — slides for your presentation
- `figures/` — exported chart images used in the report/slides (e.g., the confusion
  matrix, feature importance chart, class imbalance bar chart)

**Rule of thumb:** everything here should be a finished, polished artifact meant for
someone outside the team to read — not a work-in-progress notebook.
