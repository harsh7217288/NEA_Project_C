# data/

This folder holds the project's datasets. It is split into two subfolders:

## data/raw/

The untouched dataset exactly as downloaded — do not edit files here by hand.

**What goes here:** `neo_data.csv` (the Kaggle NASA Near-Earth Objects dataset).
Download it yourself from:
https://www.kaggle.com/datasets/sameepvani/nasa-nearest-earth-objects
and place the CSV in this folder. It is NOT pushed to GitHub (see root `.gitignore`) —
every teammate downloads their own copy locally so the repo stays small.

## data/processed/

Cleaned/transformed versions of the data, produced by scripts in `src/` or notebooks
in `notebooks/`. Example: `nea_clean.csv` — the output after removing duplicates,
dropping useless columns, and fixing units (Week 2 work).

Like `data/raw/`, this is also excluded from Git — it's meant to be regenerated by
running the cleaning script/notebook, not stored as a static file in the repo.

**Rule of thumb:** if you can regenerate a file by re-running code, it doesn't belong
in Git. Only the _code that produces it_ gets committed.
